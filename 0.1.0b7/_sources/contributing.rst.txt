Contributing
============

See the project contribution guide in
`CONTRIBUTING.md <https://github.com/jmineau/arl-met/blob/main/CONTRIBUTING.md>`_.

For local development commands, installation, and documentation build steps,
see :doc:`installation`. :doc:`development` has reference notes on arl-met's
internals: the HYSPLIT routines it mirrors, the vertical-axis conversions, the
module imports, and benchmarks.

This project is developed with the help of AI coding agents, directed and
reviewed by the maintainer, who owns the design and the science. If you
contribute with an agent, ``AGENTS.md`` at the repository root is the
orientation file it should read.
