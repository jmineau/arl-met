arl-met#

Read and analyze ARL meteorological files.

arl-met reads, writes, subsets, and samples NOAA ARL meteorology files used by HYSPLIT and STILT. The documentation is organized by task: start with the quick start, move to the user guides for downloading and cropping data, and then use the API reference for the full object model.

Getting Started

Install arl-met and open your first ARL file

Start with installation, the quickstart workflow, and the shortest path from file on disk to xarray dataset.
User Guides

Download, crop, sample, and write ARL data

Use task-focused guides for NOAA archive downloads, spatial cropping, level selection, point sampling, vertical coordinates, concatenating files, and writing datasets back to ARL files.
API Reference

Explore the full function, class, and source API

Jump into the grouped API reference for top-level I/O, the low-level file model, metadata classes, and archive source objects.
