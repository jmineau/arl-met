Quick Start#

This page shows the shortest useful end-to-end workflow: open an ARL file, inspect a few variables, crop it to a smaller domain, and write the result back to disk.

Open a file lazily with xarray#

The main entry point is arlmet.open_dataset(). It returns an xarray.Dataset backed by lazy ARL reads, so variables are unpacked only when you actually access them.

Surface variables (e.g. PRSS, SHGT) have dimensions (time, lat, lon) and upper-air variables (e.g. UWND, VWND, TEMP) have dimensions (time, level, lat, lon). The level coordinate contains only the upper-air pressure levels. ds.isel(level=0) selects the first upper-air level for upper-air variables and leaves surface variables unchanged.

import arlmet

ds = arlmet.open_dataset("path/to/file.arl")
print(ds)
print(ds["PRSS"].dims)  # ('time', 'lat', 'lon')
print(ds["UWND"].dims)  # ('time', 'level', 'lat', 'lon')
ds.isel(level=0)        # selects first upper level; surface vars unchanged

arlmet also registers itself as an xarray backend, so the same Dataset is available through xarray.open_dataset() with engine="arl". That route adds xarray’s generic options, such as chunks= for dask-backed arrays:

import xarray as xr

ds = xr.open_dataset("path/to/file.arl", engine="arl")
ds = xr.open_dataset("path/to/file.arl", engine="arl", chunks={"time": 1})

ARL files have no standard extension, so xarray recognizes them by their first record: xr.open_dataset("path/to/file.arl") works without engine= too, as long as no other installed backend claims the file first.

Select a smaller domain while reading#

Pass bbox= and levels= to crop before unpacking.

import arlmet

ds = arlmet.open_dataset(
    "path/to/file.arl",
    bbox=(-114.0, 39.0, -110.0, 42.0),
    levels=[0, 1, 2],
)

Write a cropped copy to a new ARL file#

Use arlmet.extract_subset() when you want a new ARL file on disk rather than an in-memory xarray subset.

import arlmet

arlmet.extract_subset(
    "path/to/file.arl",
    "path/to/cropped.arl",
    bbox=(-114.0, 39.0, -110.0, 42.0),
    levels=[0, 1, 2],
)

Modify a file and write it back#

Use arlmet.open_dataset() and arlmet.write_dataset() for the common case where surface variables have no level dimension and upper-air variables share one level coordinate.

import arlmet

ds = arlmet.open_dataset("path/to/file.arl")
ds["TEMP"] = ds["TEMP"] - 273.15
arlmet.write_dataset(ds, "path/to/edited.arl")

If you need a trailing DIF record for a parent variable, set the parent DataArray’s diff attr before writing:

ds["WWND"].attrs["diff"] = "DIFW"
arlmet.write_dataset(ds, "path/to/edited-with-diff.arl")

For irregular files, including per-variable forecast hours, see Writing ARL Files for the low-level arlmet.File workflow.

Sample variables at arbitrary points#

Use arlmet.sample_points() for trajectory or receptor-style sampling.

import pandas as pd
import arlmet

points = pd.DataFrame(
    {
        "lon": [-111.9],
        "lat": [40.7],
        "z": [850.0],
        "time": ["2024-07-18 00:00"],
    }
)
samples = arlmet.sample_points("path/to/file.arl", points, ["UWND", "VWND"])
